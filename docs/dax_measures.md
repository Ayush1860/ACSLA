# DAX Measures

> Generated by `scripts/build_pbip.py` from the same definitions that build the semantic model (`powerbi/AirlineAnalytics.SemanticModel/definition/tables/*.tmdl`). Edit the script, not this file.

Conventions: `%` measures return a ratio formatted as a percentage; `pts` measures return percentage points (already multiplied by 100). Service-rating measures ignore rating 0 ("not applicable").

## Core

### Total Passengers
*Home table:* `Fact_Flights` · *Format:* `#,0`

Number of passengers (one row per passenger in Fact_Flights).

```DAX
Total Passengers = COUNTROWS(Fact_Flights)
```

### Satisfied Passengers
*Home table:* `Fact_Flights` · *Format:* `#,0`

Passengers who rated the airline 'satisfied'.

```DAX
Satisfied Passengers = CALCULATE([Total Passengers], Fact_Flights[is_satisfied] = 1)
```

### Dissatisfied Passengers
*Home table:* `Fact_Flights` · *Format:* `#,0`

Passengers who were neutral or dissatisfied.

```DAX
Dissatisfied Passengers = [Total Passengers] - [Satisfied Passengers]
```

### Satisfaction %
*Home table:* `Fact_Flights` · *Format:* `0.0%`

Share of passengers who are satisfied.

```DAX
Satisfaction % = DIVIDE([Satisfied Passengers], [Total Passengers])
```

### Satisfaction vs Overall pts
*Home table:* `Fact_Flights` · *Format:* `+0.0" pts";-0.0" pts";0.0" pts"`

Percentage-point difference between the current selection and all passengers.

```DAX
Satisfaction vs Overall pts = ([Satisfaction %] - CALCULATE([Satisfaction %], REMOVEFILTERS())) * 100
```

## Delay

### Avg Dep Delay
*Home table:* `Fact_Flights` · *Format:* `0.0`

Average departure delay in minutes.

```DAX
Avg Dep Delay = AVERAGE(Fact_Flights[dep_delay])
```

### Delayed %
*Home table:* `Fact_Flights` · *Format:* `0.0%`

Share of passengers whose departure was more than 15 minutes late.

```DAX
Delayed % =
DIVIDE(
    CALCULATE([Total Passengers], Fact_Flights[dep_delay] > 15),
    [Total Passengers]
)
```

### Satisfaction % (On Time)

Satisfaction % for flights that departed on time (0 min delay).

```DAX
Satisfaction % (On Time) = CALCULATE([Satisfaction %], Fact_Flights[dep_delay] = 0)
```

### Satisfaction % (Delayed >15)
*Home table:* `Fact_Flights` · *Format:* `0.0%`

Satisfaction % for departures more than 15 minutes late.

```DAX
Satisfaction % (Delayed >15) = CALCULATE([Satisfaction %], Fact_Flights[dep_delay] > 15)
```

### Satisfaction % (Delayed >60)
*Home table:* `Fact_Flights` · *Format:* `0.0%`

Satisfaction % for departures more than 60 minutes late.

```DAX
Satisfaction % (Delayed >60) = CALCULATE([Satisfaction %], Fact_Flights[dep_delay] > 60)
```

### Delay Impact pts
*Home table:* `Fact_Flights` · *Format:* `+0.0" pts";-0.0" pts";0.0" pts"`

Points of satisfaction lost versus an all-on-time baseline.

```DAX
Delay Impact pts = ([Satisfaction % (On Time)] - [Satisfaction %]) * 100
```

### Delay Penalty >15 pts
*Home table:* `Fact_Flights` · *Format:* `+0.0" pts";-0.0" pts";0.0" pts"`

Satisfaction gap between on-time and >15 min delayed passengers.

```DAX
Delay Penalty >15 pts = ([Satisfaction % (On Time)] - [Satisfaction % (Delayed >15)]) * 100
```

## What-if

### Projected Satisfaction %
*Home table:* `Fact_Flights` · *Format:* `0.0%`

Satisfaction % if the selected share of >15 min delays were eliminated.

```DAX
Projected Satisfaction % =
VAR r = [Delay Reduction Value] / 100
VAR OnTimeRate = CALCULATE([Satisfaction %], Fact_Flights[dep_delay] <= 15)
VAR DelayedPax = CALCULATE([Total Passengers], Fact_Flights[dep_delay] > 15)
VAR DelayedSat = CALCULATE([Satisfied Passengers], Fact_Flights[dep_delay] > 15)
-- a share r of delayed passengers becomes on time and behaves like on-time passengers
VAR Recovered = r * (DelayedPax * OnTimeRate - DelayedSat)
RETURN
    DIVIDE([Satisfied Passengers] + Recovered, [Total Passengers])
```

### Projected Gain pts
*Home table:* `Fact_Flights` · *Format:* `+0.0" pts";-0.0" pts";0.0" pts"`

Satisfaction points gained under the what-if delay reduction.

```DAX
Projected Gain pts = ([Projected Satisfaction %] - [Satisfaction %]) * 100
```

### Delay Reduction Value
*Home table:* `Delay Reduction` · *Format:* `0`

What-if parameter: % of >15 min delays eliminated (0-100).

```DAX
Delay Reduction Value = SELECTEDVALUE('Delay Reduction'[Delay Reduction %], 0)
```

## Service

### Avg Service Rating
*Home table:* `Fact_Service_Ratings` · *Format:* `0.00`

Average 1-5 rating; 0 ('not applicable') is excluded.

```DAX
Avg Service Rating = CALCULATE(AVERAGE(Fact_Service_Ratings[rating]), Fact_Service_Ratings[rating] > 0)
```

### Service Gap
*Home table:* `Fact_Service_Ratings` · *Format:* `0.00`

Distance from a perfect 5 - larger = more room to improve.

```DAX
Service Gap = 5 - [Avg Service Rating]
```

### Avg Rating (Satisfied)
*Home table:* `Fact_Service_Ratings` · *Format:* `0.00`

Average rating given by satisfied passengers.

```DAX
Avg Rating (Satisfied) = CALCULATE([Avg Service Rating], Fact_Flights[is_satisfied] = 1)
```

### Avg Rating (Dissatisfied)
*Home table:* `Fact_Service_Ratings` · *Format:* `0.00`

Average rating given by neutral or dissatisfied passengers.

```DAX
Avg Rating (Dissatisfied) = CALCULATE([Avg Service Rating], Fact_Flights[is_satisfied] = 0)
```

### Rating Gap (Sat vs Dissat)
*Home table:* `Fact_Service_Ratings` · *Format:* `0.00`

How much better satisfied passengers rate a service - a proxy for its influence.

```DAX
Rating Gap (Sat vs Dissat) = [Avg Rating (Satisfied)] - [Avg Rating (Dissatisfied)]
```

### Low Rating %
*Home table:* `Fact_Service_Ratings` · *Format:* `0.0%`

Share of applicable ratings that are 1 or 2.

```DAX
Low Rating % =
DIVIDE(
    CALCULATE(COUNTROWS(Fact_Service_Ratings), Fact_Service_Ratings[rating] IN {1, 2}),
    CALCULATE(COUNTROWS(Fact_Service_Ratings), Fact_Service_Ratings[rating] > 0)
)
```

### Not Applicable %
*Home table:* `Fact_Service_Ratings` · *Format:* `0.0%`

Share of ratings recorded as 0 (service not applicable).

```DAX
Not Applicable % =
DIVIDE(
    CALCULATE(COUNTROWS(Fact_Service_Ratings), Fact_Service_Ratings[rating] = 0),
    COUNTROWS(Fact_Service_Ratings)
)
```

## What-if parameter

`Delay Reduction` is a calculated table (`SELECTCOLUMNS(GENERATESERIES(0, 100, 5), "Delay Reduction %", [Value])`). Put `Delay Reduction[Delay Reduction %]` in a single-select slicer (style: *Single value* / slider) on the Delay Impact page; `[Projected Satisfaction %]` and `[Projected Gain pts]` respond to it.

**Projection logic:** a share *r* of passengers delayed more than 15 minutes is assumed to depart on time instead and to be satisfied at the same rate as passengers who were on time (≤ 15 min). Everyone else is unchanged.
